给太多人看的日记

这里记的是很小的事：早上煮的粥稠了一点，楼下的猫换了个位置晒太阳， 下班路上闻到谁家在炖汤。没有什么道理，也不需要有什么道理。

写下来，是因为过两天就会忘。翻回去看，才发现原来那天心里挺安静的。

加密方式AES-256-GCM

为什么打开要先输密码

这些字只写给少数人看。日记正文、照片都存在公开的 GitHub 仓库里，但都是加密后的密文——没有密码，谁也读不出一句话。

加密在本机浏览器完成：密码经过 PBKDF2 派生出密钥，内容用 AES-256-GCM 封起来。密码不上传，也不存在服务器上，所以忘了就只能重新开始。

它是怎么运行的

纯静态站点，跑在 GitHub Pages 上，没有后端、没有数据库，也不放统计脚本。

同一个链接，手机和电脑都能读，读的是同一份密文。

新的一页在「写日记」里写好，加密后直接提交进仓库，几十秒后就能读到。
