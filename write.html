先连上你的 GitHub（只做一次）

文章要保存到你的仓库，所以需要一个只有这台设备知道的「钥匙」。它不会出现在网页里，只存在你本机浏览器。

  1. 打开 GitHub 令牌页面（可能需要先登录）。
  2. Token name 随便填，例如 拾光写作；Expiration 选 No expiration 或一年。
  3. Repository access 选 Only select repositories，勾上 githubnotes。
  4. Permissions → Repository permissions → Contents 设为 Read and write。
  5. 点最下面 Generate token，复制以 github_pat_ 开头的那串，粘贴到下面。
